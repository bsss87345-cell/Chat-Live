# تطبيق مجتمعنا (Mujtamauna) 🌟

تطبيق تواصل اجتماعي عربي متكامل، يجمع بين غرف المحادثات الصوتية والتفاعلية، الألعاب الجماعية الكلاسيكية (الدومينو الفاخرة، وغيرها)، نظام الفرق والتحديات، والمحفظة الرقمية.

---

## ✨ المميزات الرئيسية
- 🔐 **تسجيل الدخول والمصادقة:** شاشة تسجيل دخول وإنشاء حساب تدعم جوجل وفيسبوك مع نافذة استئذان تفاعلية للصلاحيات وتوليد معرّف رقمي فريد مكون من 8 أرقام لكل مستخدم بدلاً من اسم مستخدم إنجليزي.
- 💬 **غرف المحادثة والتواصل:** استكشاف وإنشاء غرف دردشة عامة وخاصة ومحمية بكلمة مرور، دعم الرسائل النصية، الصوتية، والهدايا.
- 🎲 **الألعاب الجماعية:** لعبة الدومينو الفاخرة المصممة لطاولة شخصين (طراز خشبي داكن، قماش أخضر، زخارف ذهبية ملكية، رف لقطع كل لاعب، ومنطقة مركزية للعب التتابعي).
- 🛡️ **نظام الفرق والتحديات:** إنشاء الفرق والانضمام إليها، نظام الإحالات ودعوة الأصدقاء، وقائمة المتصدرين.
- 💰 **المحفظة والمتجر:** رصيد العملات والمكافآت اليومية وسجل المعاملات.
- 🌐 **دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL):** تجربة استخدام مخصصة ومريحة للمستخدم العربي.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **لغة البرمجة:** Kotlin
- **واجهة المستخدم:** Jetpack Compose & Material Design 3
- **إدارة الحالة والتدفق:** ViewModel, Coroutines, StateFlow
- **نظام التوثيق والمصادقة:** Android Credential Manager & Google ID Option
- **إدارة البيئة والأسرار:** Secrets Gradle Plugin
- **الاختبارات والتأكيد البصري:** JUnit, Robolectric, Roborazzi

## 🚀 تعليمات البناء والتشغيل (Build & Run)

### 1. المتطلبات الأساسية
- Android Studio Ladybug أو أحدث (أو بيئة JDK 17 / 21)
- Android SDK Platform 36 (minSdk: 24, targetSdk: 36)

### 2. إعداد المفاتيح والمتغيرات
انسخ ملف الإعداد النموذجي:
```bash
cp .env.example .env
```
وقم بملء المفاتيح الخاصة بك (مثل `GOOGLE_CLIENT_ID` أو `FACEBOOK_APP_ID`) إن أردت ربطها بحساباتك السحابية.

### 3. بناء ملف APK للتثبيت المباشر (Debug APK)
لبناء ملف الـ APK الخاص بالاختبار مباشرة:
```bash
gradle :app:assembleDebug
```
يتم توليد ملف الـ APK في المسار التالي:
```
app/build/outputs/apk/debug/app-debug.apk
```
يمكن تثبيته مباشرة على أي هاتف أندرويد عبر الأمر:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 4. تشغيل الاختبارات البرمجية
```bash
gradle :app:testDebugUnitTest
```

## 📂 هيكل المشروع (Project Structure)
```
├── app/
│   ├── src/
│   │   ├── main/
│   │   │   ├── java/com/example/
│   │   │   │   ├── model/          # نماذج البيانات (Auth, Social, Domino Game, Room, Team)
│   │   │   │   ├── ui/             # واجهات Jetpack Compose
│   │   │   │   │   ├── components/ # العناصر المشتركة (TopBar, BottomNav, etc.)
│   │   │   │   │   ├── screens/    # الشاشات (Auth, DominoTable, Chat, Feed, etc.)
│   │   │   │   │   └── theme/      # الهوية البصرية والألوان الملكية
│   │   │   │   └── viewmodel/      # نموذج العرض الموحد SocialAppViewModel
│   │   │   └── res/                # الموارد والقيم والنصوص والأيقونات
│   │   └── test/                   # اختبارات Robolectric و Unit Tests
│   └── build.gradle.kts            # إعدادات تطبيق أندرويد والمكتبات
├── .env.example                    # نموذج المتغيرات والمفاتيح
├── .gitignore                      # استبعاد مخلفات البناء والأسرار والمفاتيح
├── README.md                       # دليل المشروع
└── settings.gradle.kts             # إعدادات المشروع وجرادل
```
